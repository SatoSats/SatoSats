## 🛠️ Progetti

### 🎲 SeedGen

**SeedGen** è un generatore open source di mnemonic BIP39 basato su entropia fisica ottenuta da dadi D6.

Il progetto nasce con l’obiettivo di rendere la generazione della seed più trasparente e verificabile, accompagnando l’utente nella procedura senza dover eseguire manualmente tutti i calcoli.

[➡️ Scopri SeedGen su GitHub](https://github.com/SatoSats/SeedGen)
